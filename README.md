# TSP Apps
Aplicaciones para la Trimui Smart Pro

Listas para usar:

* Calculadora
* Reloj
* Calendario
* Gamepad a PC
* Reproductor de Musica
* FTP con interfaz gráfica
* Usar la consola como Mando Xinput/Xbox

# Como instalar:
Descargar las apps desde [Releases](https://github.com/AleWiccan/TSP-Apps/releases/) y descomprimir las apps en la raiz de la MircroSD.
